# Crypto and stock APIs for this app

Research date: **20 October 2026**. Updated for the user's **Singapore** clarification: crypto now; **Singapore-listed SGX stocks/ETFs first**, with SGD support. US stocks are secondary future coverage. Living in Singapore and supporting Singapore-listed stocks are different requirements; this revision addresses the latter. Prices below are USD, monthly billing unless stated otherwise; verify checkout and contractual entitlements before purchasing.

## Recommendation

**Use CoinGecko as the principal crypto catalog, market snapshot and historical-price provider. For SGX, investigate EODData for an end-of-day prototype and request its commercial quote; ICE explicitly documents SGX price/history API coverage as another licensed option. Twelve Data is a conditional vendor enquiry, not a verified self-serve SGX price feed.** A workable inexpensive public SGX pricing subscription was **not established** by the reviewed sources. Separate data retrieval from allocation arithmetic, explanations and scenario validation. [EODData SGX symbols](https://www.eoddata.com/stocklist/SGX.htm), [commercial feeds](https://www.eoddata.com/products/datafeed.aspx), [ICE SGX coverage](https://developer.ice.com/fixed-income-data-services/catalog/singapore-exchange-sgx), [Twelve Data EOD restrictions](https://support.twelvedata.com/en/articles/12682324-end-of-day-eod-pricing-market-data).

For a zero-budget portfolio prototype, use CoinGecko Demo for recent crypto data with attribution and conservative caching; leave SGX prices honestly unavailable or use clearly labelled synthetic development fixtures while obtaining a quote. This is **not an established zero-cost license for public production features**. CoinGecko's paid plans explicitly include public-display commercial rights. Basic is the inexpensive crypto display option, while **Analyst is the relevant historical-data tier for existing long-horizon research**. [CoinGecko pricing](https://www.coingecko.com/en/api/pricing), [CoinGecko licensing](https://www.coingecko.com/en/api/enterprise/data-license).

**Correction to the earlier Coinbase recommendation:** Coinbase Exchange has technically useful public USD feeds, but its current market-data terms restrict external display, derived valuations and AI/ML uses absent permission. It is not a drop-in licensed source for this public AI app. Obtain appropriate written rights or replace the existing order-book evidence dependency before public enablement. [Coinbase market-data terms, updated 7 August 2026](https://www.coinbase.com/legal/market_data).

No provider subscription proves that the app's forecasts are accurate. More data enables evaluation; it does not establish predictive skill.

## 1. What the repository actually needs

The following are observations from this repository, rather than vendor claims:

- `backend/app/binance.py` powers the existing market feed with Binance pairs quoted in **USDT**. The specialist service independently uses CoinGecko **USD** snapshots/history in `lib/analysis/data.ts`. Fixing one does not fix the other.
- `data.ts` hardcodes `api.coingecko.com` and `x-cg-demo-api-key`, with `COINGECKO_DEMO_API_KEY`. Buying a paid plan also requires a **Pro host/key-header adapter change**; it is not only a new environment value. CoinGecko documents separate key types and hosts. [Authentication errors](https://docs.coingecko.com/docs/errors-and-rate-limits).
- The specialist catalog contains Bitcoin, Ethereum and Solana; correlations require exactly aligned dates. `collectEvidence()` unconditionally calls the Coinbase USD book adapter for each asset and optionally adds NewsData reports. **Buying CoinGecko Analyst alone therefore does not resolve the full public-analysis dependency.** Verified unlock and incident coverage is missing.
- The scenario gate needs **730 training returns + horizon returns + 19 × 30 days of rolling origins**. Thus 1/3/5 years require at least **1,666 / 2,396 / 3,126 daily prices**, roughly **4.6 / 6.6 / 8.6 years**. This is the current code's requirement, not a universal forecasting rule. Its request is 3,650 days.
- The current scenario engine requires contiguous UTC daily observations and 365-day years. Stocks need a **session/calendar-aware methodology**, not weekend forward-filling to make crypto validation pass. See `docs/FINANCIAL_ENGINE.md` and `lib/finance/scenarios.ts`.

CoinGecko `/coins/markets` provides prices, market cap, volume and supply fields; `/coins/{id}` provides metadata and contract/platform identity. Use canonical IDs and chain/contract addresses rather than symbols alone. Its `market_chart` daily price observations are **not exchange OHLCV candles**: preserve that distinction when charting, calculating returns or comparing providers. The documented daily series uses 00:00 UTC, with the completed day available after 00:10 UTC. [Markets](https://docs.coingecko.com/reference/coins-markets), [coin metadata](https://docs.coingecko.com/reference/coins-id), [historical chart semantics](https://docs.coingecko.com/reference/coins-id-market-chart).

CoinGecko is not a substitute for executable order-book depth: the existing Coinbase evidence is one venue and a different data product. If permission is unavailable, explicitly show liquidity evidence unavailable or contract a properly licensed book source; do not relabel aggregate 24-hour volume as executable depth. Coinbase book levels 1/2 are aggregated. [Coinbase book API](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-book).

For Binance archive ingestion, handle the documented **microsecond spot timestamps from January 2025**, validate checksums and preserve downloaded versions because archives can be corrected later. Do not silently interpret USDT as USD or join spot and futures prices. [Archive format and updates](https://github.com/binance/binance-public-data).

### Licensing and availability decisions

CoinGecko paid public display is expressly supported with attribution; API access resale/redistribution requires additional rights. The fetched licensing page lists AI and third-party-AI FAQs but did not expose their answers. **Confirm external LLM inference, provider retention, model evaluation/training and stored evidence rights for this exact architecture** rather than treating a display license as an AI-training license. Demo public/commercial eligibility should likewise be confirmed for the intended public portfolio deployment. [License options](https://www.coingecko.com/en/api/enterprise/data-license), [API terms §§3–4](https://www.coingecko.com/en/api_terms).

An earlier 3,650-day CoinGecko attempt returned HTTP 401, recorded in `FINANCIAL_ENGINE.md`; that alone does not establish the exact cause. Current docs distinguish missing/invalid keys, wrong Demo/Pro hosts and plan-restricted endpoints. Diagnose the response code/body safely and test the correct authenticated plan. [Errors](https://docs.coingecko.com/docs/errors-and-rate-limits).

Test access from the actual deployment region and IP before selection; exchange access and data licenses are separate from trading-account eligibility. CoinGecko's terms also incorporate excluded-country restrictions. Do not assume developer-machine access proves deployment access. [CoinGecko API terms §11](https://www.coingecko.com/en/api_terms).

**Start SGX with end-of-day data**, labelled with trading date and confirmation status. Real-time is unnecessary for 1/3/5-year research and can add licensing/operational complexity. No source above establishes a free, publicly redistributable live SGX feed. The SGX policy covers real-time, delayed, EOD and historical variants; delaying prices does not automatically remove licensing requirements. The current policy landing page could not be read beyond its browser-compatibility response, so confirm current rules directly rather than treating the 2022 fee schedules as current. [SGX policy landing page](https://www.sgx.com/data-connectivity/market-data-policy), [readable official policy](https://www.datadirect.sgx.com/Portals/0/Documents/Market-Data-Policy/SGX%20Market%20Data%20Policy_1%20January%202022_2.pdf).

**SGD is a calculation change, not just a display setting.** Current portfolio endpoints accept USD marks. Add explicit instrument/quote/base currencies and dated FX conversion before combining SGD holdings with USD crypto. Convert historical values using matching dated rates when measuring SGD returns; an SGD currency dropdown must not merely replace the `$` symbol. Persist original purchase currency, fees and FX so later contributions and exchange-rate gains reconcile. Verify currency per listing rather than assuming every SGX instrument trades in SGD.

The SGX adapter must use actual exchange sessions, holidays, auctions, lunch break and delisting/suspension events. Twelve Data's XSES page lists **09:00–12:00 and 13:00–17:00 Asia/Singapore**; do not force this into the crypto engine's contiguous UTC calendar. For primary company evidence, request SGX issuer announcements/corporate actions and company reports; US SEC filings below are supplemental for future US coverage. [XSES sessions](https://twelvedata.com/exchanges/xses), [SGX feed definitions](https://www.datadirect.sgx.com/Portals/0/Documents/Market-Data-Policy/SGX%20Market%20Data%20Policy_1%20January%202022_2.pdf).

### Stock-specific data quality

- **Adjustments:** Massive REST aggregates are split-adjusted by default, **not dividend-adjusted**; raw trades and flat files are unadjusted. Store raw prices and corporate actions, then explicitly choose price return versus total return. Alpha Vantage's adjusted convention includes splits and cash dividends. Do not mix these series as interchangeable closes. [Massive adjustment semantics](https://massive.com/knowledge-base/article/is-massives-stock-data-adjusted-for-splits-or-dividends), [Alpha Vantage adjustment explanation](https://www.alphavantage.co/support/).
- **Identity and delistings:** Alpaca historical `asof` handles renames differently from latest quotes; OTC data needs special entitlement. Test delisted names, acquisitions and symbol reuse explicitly. A current ticker list is not a historical investment universe. [Alpaca FAQ](https://docs.alpaca.markets/us/docs/market-data-faq), [Massive ticker reference](https://massive.com/docs/rest/stocks/tickers/all-tickers).
- **Calendars:** ingest exchange sessions, holidays, early closes and timezone/DST; distinguish regular from extended hours. Market status is a separate API, not a reason to mark every closed-market quote stale after 15 minutes. [Massive market status](https://massive.com/docs/rest/stocks/market-operations/market-status).
- **Fundamentals:** add **SEC EDGAR** for primary US filings and XBRL financial facts. It needs no API key, exposes filing histories and updates as filings arrive; fetch server-side because CORS is unsupported. Track filing/acceptance dates, amendments and units so later restatements do not leak into historical tests. [SEC API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces).
- **News:** Massive exposes ticker-linked articles, summaries, publishers, links and sentiment, but this is not verification of the article or entitlement to republish full text. Keep original publisher links and distinguish reports from company filings. [News endpoint](https://massive.com/docs/rest/stocks/news). Retain the existing optional NewsData integration until a separate cost/licensing decision; this research did not establish its current paid tiers.

## 5. Integration sequence and acceptance checks

1. **Crypto data first:** introduce an explicit provider configuration for Demo/Pro, separate canonical identity from venue pair, and define normalized price/history contracts including quote currency, feed, timestamps, observed/received time, adjustment convention and license provenance. Keep existing API keys server-only.
2. **Control request costs:** batch market snapshots, cache upstream market evidence independently of private user results, deduplicate concurrent refreshes and use bounded backoff for 429/transient failures. One cached snapshot/minute continuously is approximately **43,200 calls/month**, already beyond Demo's 10,000 before history requests; start with a conservative shared schedule. Do not disable an upstream cache merely because a private result endpoint uses `no-store`.
3. **Resolve liquidity and AI rights:** replace or license Coinbase evidence before enabling public analysis; obtain written clarity on CoinGecko-to-LLM processing and dataset retention. Keep unavailable evidence explicit.
4. **Ingest and audit historical data offline:** record retrieval date, provider/plan, actual first/last observations, missing/duplicate rows, currency and checksum. Separate independent dataset revisions. Verify actual per-asset coverage before attempting every horizon. Never fabricate a young coin's prelaunch prices.
5. **Run real evaluations:** keep the existing scenario gates closed until each asset and joint portfolio passes the accepted historical/stress/benchmark review. A more expensive API must not bypass the methodological gate. Add a separate stock methodology before stock projections.
6. **Singapore stock release:** test EODData's SGX entitlement and request EODData, ICE and SGX/vendor quotes for precise SGX symbols (for example DBS D05 and STI ETF ES3), EOD display, >=10-year daily research history where available, raw/adjusted closes, splits/dividends, announcements, calendars, delistings, SGD/FX, AI processing, storage and public user count. Ask Twelve Data whether SGX pricing can be licensed at all before comparing its quote. Keep US Alpaca/Massive evaluation separate.

Before calling a source operational, exercise authentication, representative quotes, old daily pages, pagination, 429 behavior, invalid symbols, stale values and deployment-region access. For stocks include a split, dividend, renamed ticker, delisting, holiday and early-close example. Verify the supplied feed's actual venue coverage and contracted display/derived-use rights separately.

## Evidence status and remaining decisions

This research read current official documentation, pricing pages, provider terms and Binance's official source repository using web retrieval. **It did not create provider accounts, buy plans, run authenticated paid API calls, download complete histories or establish a working deployment connection.** The earlier HTTP 401 is a repository-recorded attempt, not a new access test here.

Unresolved before implementation: budget, actual SGX API access and quote, written AI/retention and public-display permissions, actual history completeness per asset, Coinbase replacement/permission, verified unlock/incident sources, SGD/FX treatment, and the stock total-return/calendar convention. Singapore residency does not establish broker eligibility or API entitlement; no geographic deployment access was tested. The recommendation is provider selection and integration planning, not a claim that these external services are already connected.
